Sistema de Monitoreo IoT – Ecocontrol
Proyecto académico enfocado en el monitoreo de variables ambientales utilizando tecnología IoT.

Tecnologías utilizadas
  * ESP32
  * MQTT
  * Sensores (temperatura, humedad, luz)
  * Programación en C/C++
 
Funcionalidades
  * Captura de datos ambientales en tiempo real
  * Envío de datos mediante protocolo MQTT
  * Visualización de información para monitoreo

Descripción del proyecto
Se integraron sensores con ESP32 para medir variables ambientales y enviar los datos a través de MQTT, permitiendo el monitoreo remoto de las condiciones del entorno.

Objetivo
Desarrollar un sistema IoT funcional para el monitoreo ambiental en tiempo real.
